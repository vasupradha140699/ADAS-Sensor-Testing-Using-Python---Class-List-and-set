# ADAS Sensor Testing Using Python

## Description
A Python project that simulates basic ADAS sensor validation using classes, lists, and sets. It validates camera, LiDAR, and ultrasonic sensor detection ranges and generates PASS/FAIL test results.

## Features
- Sensor details management using classes and objects
- Detection range validation for different sensor types
- Passed and failed sensor ID tracking
- Adding, updating, and deleting sensor records
- List and set operations, including union, intersection, and difference
- Counting passed and failed test cases

## Technologies
Python, Object-Oriented Programming (OOP), Lists, Sets

## Objective
To practice Python programming concepts and apply them to basic automotive ADAS sensor testing scenarios.

**Note:** This is a simulation using example detection-range limits, not validation of real sensor specifications.
